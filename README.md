#What is ML?
Machine Learning is a branch of Artificial Intelligence (AI) where computers learn patterns from data and make decisions/predictions without being explicitly programmed.
#Types of Machine Learning
#Supervised Learning
• Data: Labeled (input + output given).
• Goal: Predict output for new input.
• Examples: 
• Predicting house prices (Regression)
• Spam email detection (Classification)
• Algorithms: Linear Regression, Logistic Regression, Decision Trees, SVM, Neural Networks.
#Unsupervised Learning
• Data: Unlabeled (only input given).
• Goal: Find patterns or group data.
• Examples: 
• Customer segmentation
• Market basket analysis
• Algorithms: K-Means Clustering, Hierarchical Clustering, PCA (Dimensionality Reduction).
#Reinforcement Learning (RL)
• Agent learns by interacting with environment.
• Feedback: Reward/Penalty.
• Example: 
• Game playing AI (Chess, Go).
• Self-driving cars.
• Algorithms: Q-Learning, Deep Q-Networks.
#Key Concepts
• Dataset = Collection of examples (inputs + outputs).
• Training = Model learns from data.
• Testing = Checking model accuracy on new data.
• Overfitting = Model memorizes training data, fails on new data.
• Underfitting = Model too simple, can’t learn patterns.
• Bias-Variance Tradeoff = Balance between underfitting and overfitting.
 #Important Algorithms
• Regression (predict continuous values) → Linear Regression, Polynomial Regression.
• Classification (predict categories) → Logistic Regression, Naïve Bayes, Random Forest.
• Clustering → K-Means, DBSCAN.
• Neural Networks → Deep Learning models.
